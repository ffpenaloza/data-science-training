# Data Science Training

Repositorio de proyectos, ejercicios y trabajos desarrollados durante mi formación en **Data Science**.

## Proyectos

### [Coursera - Churn Challenge](./Coursera%20-%20Churn%20Challenge/)

Proyecto de predicción de abandono de clientes (*churn*) para un servicio de streaming, desarrollado en el contexto de un challenge de Coursera.

El proyecto aborda el análisis y preparación de datos, ingeniería de características (*feature engineering*), modelamiento predictivo y evaluación del modelo.

**Proyecto destacado:** [Ver Churn Prediction →](./Coursera%20-%20Churn%20Challenge/)
